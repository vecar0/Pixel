# NEON PAW — 무한 지하 아케이드

혼자서 끝없이 즐기는 **횡스크롤 액션 슈터 로그라이크**. 미소녀 3명이 무기를 줍고, 버프를 쌓아 보스가 기다리는 무한한 지하로 내려갑니다.
모든 도트(캐릭터·적·보스·무기 26종·타일·배경)는 외부 이미지 없이 코드로 한 픽셀씩 찍었어요.

## 플레이
- **폰/PC 브라우저**: GitHub Pages 주소로 접속 (가로 화면). 홈 화면에 추가하면 앱처럼 전체 화면으로 열려요.
- **로컬**: 이 폴더에서 `npx serve .` 또는 `python3 -m http.server` → `http://localhost:8000`
  (ES 모듈이라 `index.html` 파일을 더블클릭하면 브라우저가 막아요. 로컬 서버로 여세요.)

## 조작
| 행동 | PC | 모바일 |
|---|---|---|
| 이동 | A / D (←/→) | 왼쪽 화면 드래그 |
| 점프 · 공중 점프 | W / Space | 점프 버튼 |
| 발판 내려가기 | S + 점프 | 스틱 아래 + 점프 |
| 공격 (가까운 적 자동 조준) | J 또는 마우스 왼쪽(마우스 조준) | 공격 버튼 누르고 있기 |
| 스킬 | K / 우클릭 / Shift | 스킬 버튼 (쿨다운 표시) |
| 무기 교체 | Q | 교체 버튼 |
| 줍기·열기·구매·포탈 | E | 근처에서 뜨는 버튼 |
| 일시정지 | Esc | Ⅱ 버튼 |

## 게임 구성
- **캐릭터 3명**: 미유(콤보 러시: 처치할수록 지속 연장), 루나(유성우), 하루(무적 대시 베기). 보석으로 해금
- **층 구조**: 시작방 → 전투방(문 잠김 + 웨이브) → 상자/상점/축복 석상 → … → 포탈. **5층마다 보스**(킹 슬라임 / 기계 까마귀 K-9 / 그림자 메이드장)가 돌아가며 강해짐. 끝없음
- **테마 4종**: 네온 아케이드 → 슬라임 동굴 → 태엽 공장 → 어둠의 성 (5층마다 바뀌고 반복)
- **적 6종 + 엘리트 변종**: 모든 공격에 예고(느낌표·조준선·경고선)가 있어요
- **무기 26종 / 5등급**: 권총·샷건·기관단총·레이저·저격총·로켓·플라즈마·무지개 개틀링·번개(연쇄)·부메랑·냉동(감속)·검·창·대낫·빔소드(검기) 등. 근접 무기는 적 탄을 지워요
- **버프 32종**: 층을 깰 때마다 3장 중 1장. 분열탄·관통·도탄·폭발·유도·흡혈·부활·이단 점프… 중첩 가능
- **영구 성장**: 층 클리어 보석 → 캐릭터 해금, 연구소(시작 HP·에너지·코인·행운 부적·무기고 열쇠)
- 아머는 3초 안 맞으면 재생, 에너지가 0이면 근접 치기로 싸울 수 있어 막힐 일이 없어요
- 효과음·배경음은 WebAudio 칩튠으로 직접 합성. 기록은 브라우저에 저장

## 구조
```
index.html, css/style.css, fonts/ (Galmuri 픽셀 폰트, OFL)
js/data.js    캐릭터·무기·적·보스·버프·연구 데이터
js/level.js   방/층 생성
js/sim.js     게임 로직 (화면과 분리 → Node에서 테스트 가능)
js/art.js     모든 도트 그래픽 (픽셀 그리드)
js/render.js  480×270 내부 해상도 렌더러
js/input.js   키보드·마우스·터치
js/audio.js   칩튠 효과음/배경음
js/main.js    메뉴·루프·저장
design/plan.md  기획서
```

## 테스트

- `node tests/e2e.mjs` — 실제 브라우저(Playwright)로 메뉴·조작·터치·보스·사망·저장·FPS 확인
