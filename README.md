# 등불지기 (Lantern Keeper)

폰 가로 화면용 픽셀 횡스크롤 **근접 액션 로그라이크**. 꺼져 가는 지하 왕국의 대등(大燈)을 다시 켜러 내려가는 순례자 리라의 이야기.
핵심은 **패링** — 적의 공격을 사슬 랜턴으로 정확한 순간에 튕겨내는 손맛.

## 플레이
- 폰/PC 브라우저로 접속 (가로). 홈 화면에 추가하면 앱처럼 열려요.
- 로컬: 이 폴더에서 `python3 -m http.server` → `http://localhost:8000`

| 행동 | PC | 모바일 |
|---|---|---|
| 이동 | A/D, ←/→ | 왼쪽 화면 드래그 |
| 점프 (아래+점프 = 발판 내려가기) | W / Space | 점프 |
| 공격 (3연타) | J | 공격 |
| **패링** | K | 패링 |
| 회피 (구르기, 무적) | L / Shift | 회피 |
| 등불 마법 (지닌 마법 1개, 빛 소모) | I / U | 마법 |
| 기름병 (회복) | Q | 기름 |

## 구성
- **전투**: 완벽 패링 6프레임, 히트스톱·슬로모션, 자세 게이지 → 그로기 → 처형. 모든 공격에 예고(흰색=패링 가능, 빨간색=패링 불가)
- **4개 지역 · 보스 4종**: 이끼 묘지(무덤종) → 침수 대성당(침수 성녀) → 유리 광산(유리 여왕거미) → 꺼진 태양의 심연(흑염의 순례자)
- **런**: 서약 3종 → 방(전투·엘리트·휴식·상점) → 각인 3택1 → 문 2개 중 선택 → 보스. 각인 10종, 엘리트 수식어, 보스 변형 패턴, 이번 판 도전
- **등대 마을**: 등불 조각으로 각인·랜턴 기름(정제유/청유/흑유)·연습장 해금, 어둠 단계 1~10, 오늘의 시련, 기록
- **설정**: 타이밍 보정(박자 탭 측정), 효과음/배경음악

## 개발
- 그림: Higgsfield 생성 → agent-sprite-forge pixel_look로 픽셀 격자 맞춤 · 이펙트: pixelfx (MIT, `js/vendor/pixelfx`)
- 구조: `js/core/` 순수 시뮬레이션(60틱 고정, DOM 없음) · `js/render.js` · `js/main.js`
- 테스트: `npm test` (시뮬레이션·런) · `npm run e2e` (Playwright)

## 스탯 (반대 스탯 3쌍, 판마다 모두 5에서 시작, 0~10)
힘↔민첩 · 의지↔등불 · 생명↔투지. 전투방을 깨면 단련 1점: 한쪽을 올리면 반대쪽이 1 내려간다 (쌍의 합은 늘 10).
엘리트·보스방은 각인 3택1. 서약은 없다.

| 스탯 | 점마다 | 7 | 10 | 3 이하 |
|---|---|---|---|---|
| 힘 | 공격 피해 ±12% | 3타 검기 | 처형 시 주변 적 자세 +40% | 공격 후딜 +4f |
| 민첩 | 이동·구르기 ±6%, 무적 ±1f | 구르기 후딜 없음 | 구르기 직후 치명타 | 구르기 후딜 +6f |
| 의지 | 완벽 패링 판정 ±1f, 자세 피해 ±12% | 완벽 패링한 적 1.5배 오래 무방비 | 모든 패링 완벽 | 헛 패링 후딜 +6f |
| 등불 | 마법 피해 ±15%, 빛 ±10% | 등불 탄 2발 | 처치마다 빛 +15 | 마법 비용 +25% |
| 생명 | 최대 체력 ±1 | 기름병 회복 +1 | 기름병 +1개 | 기름병 회복 −1 |
| 투지 | 5 넘는 점마다 치명타 +6% | 처치 뒤 다음 공격 치명타 | 치명타 3배 | 처형 피해 −30% |

## 등불 마법 (1칸, 스탯 빌드가 정함)
마법은 하나 (키 I 또는 U, 터치 '마법'). 빛 게이지를 소모하고, 연출은 모두 pixelfx 마법 이펙트.
**가장 높은 스탯이 7 이상이면 그 스탯의 마법, 10이면 상위 마법.** 7 이상이 없으면 마을에서 고른 기름의 기본 마법(정제유 등불 탄 / 청유 푸른 결계 / 흑유 흑염 창). 동점이면 마지막으로 올린 스탯.

| 스탯 | 7 | 10 |
|---|---|---|
| 힘 | 화염 기둥 | 운석 |
| 민첩 | 얼음 창 | 별똥비 |
| 의지 | 푸른 결계 | 낙뢰 |
| 등불 | 불꽃 고리 | 흑염 창 |
| 생명 | 치유의 빛 | 성광 기둥 |
| 투지 | 연쇄 번개 | 암흑 폭발 |

| 마법 | 빛 | pixelfx | 효과 |
|---|---|---|---|
| 등불 탄 | 20 | fire/fireball | 앞으로 불덩이 |
| 얼음 창 | 30 | ice/ice-lance | 관통 |
| 화염 기둥 | 40 | fire/flame-pillar | 앞쪽 가까운 적 발밑, 착탄 0.55초 |
| 낙뢰 | 45 | lightning/lightning-strike | 가장 가까운 적, 자세 크게 |
| 별똥비 | 50 | arcane/star-fall | 앞쪽 넓은 범위 |
| 운석 | 60 | fire/meteor | 큰 폭발, 시전 중 무적 |
| 불꽃 고리 | 55 | fire/fire-ring | 주변 폭발 + 적 탄 소거, 무적 |
| 푸른 결계 | 45 | holy/divine-shield | 5초간 모든 패링 완벽, 무적 |
| 흑염 창 | 55 | arcane/arcane-beam | 앞으로 관통 광선, 무적 |
| 치유의 빛 | 50 | holy/heal | 체력 2 회복 |
| 성광 기둥 | 60 | holy/holy-pillar | 주변 피해 + 체력 1, 무적 |

## 스테이지 순서 (정해져 있음)
지역 1~3: 전투 → 전투 → 휴식 → 강적 → 상점 → 보스 / 지역 4: 전투 → 휴식 → 강적 → 상점 → 보스.
전투방 오른쪽 끝 출구는 봉인돼 있다가 적을 다 잡으면 포탈로 열린다 (보상을 고른 뒤 걸어서 나감).
보스방: 양쪽 발판 + 양쪽 끝 '등불 화로'(베면 보스 발밑 불기둥: 피해 20, 자세 +50%, 15초 재충전). 보스 공격 피해는 모두 1.
상점·휴식은 걸어 들어가는 방: 상인(상점)·모닥불(휴식) 앞에서 공격 버튼으로 이용, 오른쪽 끝 출구 포탈로 다음 스테이지.
