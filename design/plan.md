# 기획서 — 「NEON PAW: 무한 지하 아케이드」 (가제)

> 장르: 횡스크롤 액션 슈터 로그라이크 (소울나이트류 "무기 줍기 + 스킬 + 층 돌파"를 옆에서 보는 플랫포머로)
> 플레이: 혼자 vs 컴퓨터, 실시간, **끝없이 내려가는 무한 층** — 죽으면 처음부터, 대신 영구 재화로 캐릭터·특성 해금
> 캐릭터·아트·이름은 전부 오리지널 (기존 게임 캐릭터 재현 X)
> **아트 결정(유저 피드백 반영)**: AI 일러스트는 폐기. 큰 머리 치비 도트를 코드로 한 픽셀씩 직접 찍는다. 선택 화면도 같은 도트를 확대해서 보여준다.

## ② 자원 · 경제 규칙
| 자원 | 얻는 법 | 쓰는 곳 | 유지 |
|---|---|---|---|
| 코인 | 적 처치 1~3, 상자 | 층 내 상점 (무기·회복·버프) | 런 종료 시 소멸 |
| 에너지 | 처치 구슬, 상자 | 무기 발사 | 런 내 |
| **보석 (영구)** | 층 클리어 +층수, 보스 +20 | 캐릭터 해금, 영구 특성 (HP+1 등) | localStorage 저장 |

- 시작: 미유만 해금. 루나 300보석, 하루 500보석.
- **버프(특성)**: 매 층 클리어 시 3개 중 1개 선택 — 예: 탄 +1, 치명타 +10%, 스킬 쿨 -20%, 처치 시 에너지 회복, 이단 점프, 흡혈 등 **30종**, 중첩 가능 → 무한 빌드 다양성.

## ③ 적 AI · 진행 규칙
- **한 층 = 방 4~6개** 일렬 연결 (전투방 3~4 + 상자/상점/석상방 1~2). 방은 미리 만든 지형 조각 12종 × 무작위 조합으로 생성.
- 전투방 입장 시 문 잠김 → 웨이브 2~3회 → 전멸 시 문 열림 + 상자.
- 웨이브 크기: `3 + 층×0.8` 마리 (상한 14), 웨이브 간격 = 직전 웨이브 전멸 후 1초.
- 적 체력 배율: `1 + 층×0.12` / 공격 빈도 배율: `1 + 층×0.04` (상한 1.8).
- 행동: 시야(가로 14타일) 안에 들어오면 추적, 사수는 거리 5~8타일 유지하며 1.6초마다 발사(조준 0.5초 예고 표시), 근접은 1.2초 간격.
- 5층마다 보스방, 보스 체력 `기본 × (1 + 사이클×0.6)`. 15층 이후 3보스가 다시 돌며 패턴 강화 → **끝없음**.

## ④ 조작 체계 (모바일 우선 + PC)
| 행동 | PC | 모바일 (가로 화면) |
|---|---|---|
| 좌우 이동 | A/D 또는 ←/→ | 왼쪽 가상 스틱 |
| 점프 (이단점프 버프) | W / Space / ↑ | 점프 버튼 |
| 공격 (자동 조준: 가장 가까운 적) | J 또는 마우스 좌클릭(마우스 조준) | 공격 버튼 누르고 있기 |
| 스킬 | K / 우클릭 | 스킬 버튼 (쿨다운 원형 게이지) |
| 무기 교체 | Q | 교체 버튼 |
| 줍기/상호작용 | E | 근처일 때 버튼이 "줍기"로 변함 |
| 일시정지 | Esc | ⏸ 버튼 |
- 카메라: 측면 고정, 플레이어 부드럽게 추적 (방 경계에서 멈춤). 줌 없음.
- 조작키 겹침 없음 (이동=WASD, 행동=JKQE).

## ⑤ 화면 구성
- **타이틀** → **캐릭터 선택 화면** (자체 구성: 왼쪽 무대에 확대 도트 캐릭터 대기 모션, 오른쪽 정보 패널[스탯 바·기본 무기·스킬·소개], 하단 스티커 슬롯·잠금 가격, 상단 보석·연구소·조작법)
- **인게임 HUD**: 좌상단 HP/아머/에너지 바, 층·방 번호, 코인 / 우상단 미니 진행바(방 n/총) + 일시정지 / 하단 현재 무기 2칸 + 스킬 쿨 / 보스 체력바
- **버프 선택 카드 3장**, **상점 창**, **사망 결과 화면**(도달 층, 처치 수, 획득 보석, 빌드 목록), 일시정지 메뉴(음향/진동/조작 크기)

### 아트 방향
- 내부 해상도 **480×270** 픽셀 캔버스를 정수 배율로 확대 (계단현상 그대로 → 진짜 픽셀아트)
- 인게임 캐릭터: 직접 찍은 치비 도트 **약 28×34px** (머리 비중 큰 SD), 3×4 눈 + 하이라이트, 대기 4/달리기 4/점프/낙하 프레임, 자동 외곽선
- 선택 화면: 같은 도트를 정수 배율로 확대 + 흰 스티커 테두리 아이콘
- 화면 폭은 기기 비율에 맞춰 480~640px (폰 가로 화면 꽉 채움)
- 배경: 네온 지하 아케이드 → 슬라임 동굴 → 기계 공장 → 어둠 성 (5층마다 테마 변경, 패럴랙스 3겹)
- 효과음/배경음: WebAudio로 칩튠 직접 합성 (외부 파일 없음)

## ⑥ 완료 기준 체크리스트
- [ ] index.html을 열면 타이틀 → 캐릭터 선택 화면이 뜨고 콘솔 에러 0건
- [ ] 캐릭터 선택 화면에 스탯 바 4개·일러스트·스킬 설명·잠금 슬롯·보석 수가 보인다
- [ ] 키보드와 터치 둘 다로 이동·점프·공격·스킬·스왑이 된다
- [ ] 플레이어가 바닥/발판에 서고 벽을 통과하지 않는다
- [ ] 전투방 입장 시 문이 잠기고, 적 전멸 후 열린다
- [ ] 적이 실제로 추적·발사하고, 피격 시 아머 → HP 순으로 깎인다
- [ ] 무기를 쏘면 에너지가 줄고, 0이면 에너지 필요 무기를 못 쏜다
- [ ] 각 캐릭터 스킬이 쿨다운대로 발동하고 효과가 보인다 (미유 처치 시 지속 연장 포함)
- [ ] 상자에서 무기가 나오고 주워서 2개 사이 교체 가능
- [ ] 층 클리어 시 버프 3장 중 선택 → 효과가 실제 수치에 반영
- [ ] 5층에 보스가 나오고 처치 시 다음 층으로 진행
- [ ] headless 시뮬레이션으로 자동 플레이 시 30층 이상 크래시·무한루프 없이 생성된다 (무한성 확인)
- [ ] 사망 시 결과 화면 → 보석이 저장되어 새로고침 후에도 유지, 해금 가능
- [ ] 최악 장면에서 60fps 유지

## 성능 상한 (Canvas 2D 기준)
| 항목 | 상한 | 지키는 법 |
|---|---|---|
| 목표 | 60fps, 최악 장면 55+ (중급 폰) | 고정 타임스텝 60Hz 로직 |
| 최악 장면 | 적 30 + 탄 300 + 파티클 400 + 보스 | 이 장면으로 측정 |
| 동시 적 | 30 | 웨이브 상한 14 × 2 + 보스 |
| 탄/파티클 | 300 / 400 | 오브젝트 풀 재사용, 초과 시 오래된 것부터 제거 |
| 스프라이트 | 시작 시 오프스크린 캔버스에 1회 렌더 후 drawImage만 | 매 프레임 픽셀 단위 그리기 금지 |
| 타일맵 | 방마다 정적 레이어 1장으로 미리 굽기 | 화면당 drawImage 수 감소 |

## 기술
- 빌드 도구 없는 **단일 index.html + ES 모듈** (`js/`: config·sprites·level·entities·combat·input·ui·audio·main 분리), 외부 라이브러리 0개
- 로직과 렌더 분리 → Node에서 headless 시뮬레이션 테스트 가능
- GitHub Pages로 폰에서 바로 플레이 가능하게 배포
