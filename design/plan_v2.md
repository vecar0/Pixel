## ⑥ 완료 기준 체크리스트
- [ ] 주인공 스프라이트 높이 ≥ 38px, 재질별 색 4단계 이상 (팔레트 검사)
- [ ] 달리기 6프레임, 대기 4프레임이 실제로 바뀐다

- [ ] 광원이 있는 곳이 주변보다 밝다 (픽셀 밝기 비교)

### 독창 메커니즘: 「몬스터 소울」
처치한 적의 **영혼을 흡수해 그 능력을 3번째 슬롯으로 쓴다** (1개만 보유, 새로 먹으면 교체).
- 드롭: 엘리트 100%, 일반 6%, 보스 100%(강화 소울). 바닥의 소울 구슬을 줍기(E)
- 효과 (자동 발동, 쿨다운 있음):
  | 소울 | 효과 |
  |---|---|
  | 슬라임 | 착지할 때 주변에 젤리 탄 6발 |
  | 박쥐 | 공중 점프 +1, 공중 점프 시 짧은 돌진 |
  | 고블린 | 2초마다 가까운 적에게 자동 화살 |
  | 해골 | 3초마다 정면 탄 1발 막는 방패 |
  | 버섯 | 피격 시 독 포자 폭발 (주변 피해) |
  | 위습 | 주위를 도는 불꽃 2개 (접촉 피해) |
  | 보스(3종) | 슬라임왕: 착지 충격파 / 그리폰: 깃털 탄막 4초마다 / 기사단장: 공격 5회마다 검기 |
- HUD: 스킬 아이콘 옆 소울 아이콘 + 쿨다운
- 완료 기준 추가: [ ] 엘리트 처치 → 소울 드롭 → 줍기 → 효과가 실제로 발동 (sim 테스트로 9종 전부 확인)
