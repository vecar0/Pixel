# 등불지기 — 최종 설계안: 「빛 속에서만 벨 수 있다」

## 0. 한 줄
이 세계의 적은 **그림자**다. 어둠 속에선 칼이 통과하고, **등불 빛 안에 들어와야 실체가 생겨 베인다.**
전투는 *빛을 어디에 두고, 그림자를 어떻게 빛 안으로 끌어들이느냐*의 싸움이다.

**리듬:** 빛을 두고 → 그림자를 빛 안으로 → 패링으로 데게 하고 → 빛 속에서 처형 → 빛 조각으로 내 빛을 키운다.

---

## 1. 전투

### 1-1. 빛과 실체
| 규칙 | 값 |
|---|---|
| 든 등불 빛 반경 | 90px (리라 중심) |
| 던진 등불 빛 반경 | 110px |
| 빛에 들어온 그림자 → 실체화 | 0.3초 뒤 (몸이 또렷해짐 = 벨 수 있음) |
| 빛에서 나간 실체 → 그림자로 | 0.5초 뒤 (반투명·검게) |
| 그림자의 공격 | 어둠 속에서도 리라를 친다 (그래서 빛을 놓을 수 없음) |

- 그림자 상태: 칼이 통과(피해 0), 반투명 검은 몸 + 눈빛만 또렷.
- 실체 상태: 원래 그림, 피해·자세 피해 정상.

### 1-2. 동작 (버튼 6개)
| 버튼 | 하는 일 |
|---|---|
| 공격 | 3연타. 실체만 벤다 |
| 패링 | 등불로 받아냄. 완벽 패링 → 공격한 그림자가 **빛에 데어 3초 실체화** + 자세 30% / 일반 1.5초 + 자세 10% (빛 밖이어도) |
| 구르기 | 무적 구르기 |
| 점프 | |
| **등불** | 탭 = 앞으로 160px 던짐 · 길게 = 조준(스틱·A/D로 60~260px) · 던진 상태에서 탭 = **회수** |
| 기름병 | 체력 회복 (3개) |

- **던지기:** 0.4초 날아가 떨어진 자리가 6초간 빛. 그동안 리라 곁은 어둠 → **곁의 적은 못 벤다.** 6초 뒤 저절로 돌아옴.
- **회수:** 0.3초에 돌아옴. 날아오는 등불이 지나간 자리의 그림자는 **1초 실체화**.
- **던진 동안 패링 불가** (등불이 손에 없음). 구르기만.

### 1-3. 처형
- 자세 100% → **무너짐 2.5초.** 무너진 적은 **빛 안에서만** 처형할 수 있다.
- 처형 = 그림자 소멸 + **빛 조각** 획득. 처형 없이 쓰러뜨리면 빛 조각 없음.
- 연속 처형: 처형의 충격이 빛 안의 흔들리던(자세 45%↑) 그림자를 무너뜨림 → 이어서 처형.

### 1-4. 체력
- 체력 5칸 · 기름병 3개 (빛과 체력은 분리 — 빛은 위치 도구, 체력은 생존).

### 1-5. 그림자들의 빛 반응 (적마다 다르게 → 매번 다른 판단)
| 적 | 빛에 대해 | 대처 |
|---|---|---|
| 구울 | 빛을 **싫어해** 빛 가장자리를 돈다 | 던져서 빛으로 몰아넣기 |
| 나방 | 빛으로 **달려든다** | 미끼 — 던진 등불에 모인 걸 회수 궤적으로 |
| 창병 | 빛 **가장자리 밖에서** 긴 창으로 찌름 | 빛을 창병 쪽으로 옮기기 |
| 순례자 | 어둠에서 **원거리**로 쏨 | 멀리 던져 실체화 |
| 갑각수호자 | 빛 쪽으로 **방패**를 든다 | 빛을 뒤쪽에 두고 앞에서 베기 |
| 암살자 | **등불을 노린다** (맞으면 빛 2초 꺼짐) | 등불 지키기 · 패링 |
| 변종 6종 | 원래 적의 반응 + 강화 | |
| **보스** | 몸 일부만 그림자 (약점 부위) | 그 부위에 빛을 비춰야 벨 수 있음 |

## 2. 성장 — 「그림자에게서 되찾은 빛으로 내 빛을 키운다」

### 2-1. 빛 조각 (재화)
- 처형으로만: 일반 3 · 강적 10 · 보스 30.

### 2-2. 등잔 (성장하는 곳)
- 전투방에 40% 확률로 1개, 휴식처엔 항상 1개. 꺼진 채 놓여 있다.
- 빛 조각을 부어 켬: 첫 등잔 10, 켤 때마다 +5.
- 켜면 ① **색 선택** ② **빛 모양 2택 1**.

### 2-3. 등잔의 색 = 내 빛이 그림자에게 하는 일 (한 번에 한 색, 켤 때 바꿀지 선택)
| 색 | 빛 안의 그림자에게 | 칼에 옮겨붙는 효과 |
|---|---|---|
| 화염 | 초당 4 피해 | 3대마다 화상 |
| 얼음 | 이동 -40% | 3대마다 빙결 |
| 성광 | 실체화 +1초 | 3대마다 자세 붕괴 |
| 귀화 | 빛 안의 그림자가 리라를 못 봄 | 3대마다 눈멂 |
| 생명 | — | 처형마다 체력 1 |
| 번개 | 실체화된 적 120px 안 그림자도 함께 실체화 | 3대마다 감전 |

### 2-4. 빛의 모양 (등잔마다 둘 중 하나, 겹쳐 쌓임)
| 모양 | 효과 |
|---|---|
| 넓은 빛 | 빛 반경 +20% (최대 3번) |
| 오래 타는 빛 | 던진 빛 +3초 |
| 갈라지는 빛 | 던지면 반경 70짜리 빛 두 곳 |
| 빛줄기 | 든 빛이 앞으로 +80px 뻗음, 뒤는 -40% |
| 남는 빛 | 회수 궤적에 빛이 2초 남음 |
| 따라오는 빛 | 던진 빛이 천천히 리라를 따라옴 |

### 2-5. 큰 등잔 (보스)
- 보스를 처형하면 켜짐: 빛 최대 반경 +15% · 강한 모양 1개 (빛 두 개 동시 유지 / 완벽 패링 시 빛 폭발 / 던진 빛에 든 그림자 자동 실체화 유지 등).

## 3. 없어지는 것 (정리)
점화 버튼 · 소등 버튼 · 빛 게이지(→ 빛 반경·빛 조각) · 6스탯과 단련 · 속성 게이지 3대 폭발(→ 색의 칼 효과로 흡수) · 마법 각인 · 상성 ▲▼ · 마법 버튼.

## 4. 만들 그림 (Higgsfield)
| 그림 | 비고 | 크레딧 |
|---|---|---|
| 던지기 모션 8프레임 | 원본 참고 | ~0.75 |
| 받기(회수) 모션 6프레임 | | ~0.75 |
| 빈손 서기·달리기·베기·구르기 | 기존 프레임에서 등불을 코드로 지움 | 0 |
| 던진 등불·빛 반경·그림자 상태 | 코드로 그림 | 0 |
| 등잔(꺼짐/켜짐 6색) | 소품 한 장 + 코드로 색 | ~0.25 |
| (선택) 캐릭터 새 디자인 | 새 원본 + 주요 동작 전부 다시 생성 | 동작 수 × ~0.75 |

## 5. 만드는 순서
1. 빛·실체 시스템 (그림자 상태 그림·피해 규칙) + 들기/던지기/회수 + 패링 데임
2. 적 빛 반응 6종 · 보스 약점 부위
3. 처형·빛 조각·등잔·색·빛 모양
4. 옛 시스템 제거, 버튼·HUD 정리, 튜토리얼
5. 모션 생성 (던지기·받기), 캐릭터 디자인
