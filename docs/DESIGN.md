# 등불지기 — 최종 설계안: 「빛 속에서만 벨 수 있다」

## 0. 한 줄
이 세계의 적은 **그림자**다. 어둠 속에선 칼이 통과하고, **등불 빛 안에 들어와야 실체가 생겨 베인다.**
전투는 *빛을 어디에 두고, 그림자를 어떻게 빛 안으로 끌어들이느냐*의 싸움이다.

**리듬:** 빛을 두고 → 그림자를 빛 안으로 → 패링으로 데게 하고 → 빛 속에서 처형 → 빛 조각으로 내 빛을 키운다.

---

## 1. 전투

### 1-1. 빛과 실체
| 규칙 | 값 |
|---|---|
| 든 등불 빛 반경 | 90px (리라 중심) |
| 던진 등불 빛 반경 | 110px |
| 빛에 들어온 그림자 → 실체화 | 0.3초 뒤 (몸이 또렷해짐 = 벨 수 있음) |
| 빛에서 나간 실체 → 그림자로 | 0.5초 뒤 (반투명·검게) |
| 그림자의 공격 | 어둠 속에서도 리라를 친다 (그래서 빛을 놓을 수 없음) |

- 그림자 상태: 칼이 통과(피해 0), 반투명 검은 몸 + 눈빛만 또렷.
- 실체 상태: 원래 그림, 피해·자세 피해 정상.

### 1-2. 동작 (버튼 6개)
| 버튼 | 하는 일 |
|---|---|
| 공격 | 3연타. 실체만 벤다 |
| 패링 | 등불로 받아냄. 완벽 패링 → 공격한 그림자가 **빛에 데어 3초 실체화** + 자세 30% / 일반 1.5초 + 자세 10% (빛 밖이어도) |
| 구르기 | 무적 구르기 |
| 점프 | |
| **등불** | 탭 = 앞으로 160px 던짐 · 길게 = 조준(스틱·A/D로 60~260px) · 던진 상태에서 탭 = **회수** |
| 기름병 | 체력 회복 (3개) |

- **던지기:** 0.4초 날아가 떨어진 자리가 6초간 빛. 그동안 리라 곁은 어둠 → **곁의 적은 못 벤다.** 6초 뒤 저절로 돌아옴.
- **회수:** 0.3초에 돌아옴. 날아오는 등불이 지나간 자리의 그림자는 **1초 실체화**.
- **던진 동안 패링 불가** (등불이 손에 없음). 구르기만.

### 1-3. 처형
- 자세 100% → **무너짐 2.5초.** 무너진 적은 **빛 안에서만** 처형할 수 있다.
- 처형 = 그림자 소멸 + **빛 조각** 획득. 처형 없이 쓰러뜨리면 빛 조각 없음.
- 연속 처형: 처형의 충격이 빛 안의 흔들리던(자세 45%↑) 그림자를 무너뜨림 → 이어서 처형.

### 1-4. 체력
- 체력 5칸 · 기름병 3개 (빛과 체력은 분리 — 빛은 위치 도구, 체력은 생존).

### 1-5. 그림자들의 빛 반응 (적마다 다르게 → 매번 다른 판단)
| 적 | 빛에 대해 | 대처 |
|---|---|---|
| 구울 | 빛을 **싫어해** 빛 가장자리를 돈다 | 던져서 빛으로 몰아넣기 |
| 나방 | 빛으로 **달려든다** | 미끼 — 던진 등불에 모인 걸 회수 궤적으로 |
| 창병 | 빛 **가장자리 밖에서** 긴 창으로 찌름 | 빛을 창병 쪽으로 옮기기 |
| 순례자 | 어둠에서 **원거리**로 쏨 | 멀리 던져 실체화 |
| 갑각수호자 | 빛 쪽으로 **방패**를 든다 | 빛을 뒤쪽에 두고 앞에서 베기 |
| 암살자 | **등불을 노린다** (맞으면 빛 2초 꺼짐) | 등불 지키기 · 패링 |
| 변종 6종 | 원래 적의 반응 + 강화 | |
| **보스** | 몸 일부만 그림자 (약점 부위) | 그 부위에 빛을 비춰야 벨 수 있음 |

## 2. 성장 — 「그림자에게서 되찾은 빛으로 내 빛을 키운다」

### 2-1. 빛 조각 (재화)
- 처형으로만: 일반 3 · 강적 10 · 보스 30.

### 2-2. 등잔 (성장하는 곳)
- 전투방에 40% 확률로 1개, 휴식처엔 항상 1개. 꺼진 채 놓여 있다.
- 빛 조각을 부어 켬: 첫 등잔 10, 켤 때마다 +5.
- 켜면 ① **색 선택** ② **빛 모양 2택 1**.

### 2-3. 등잔의 색 = 내 빛이 그림자에게 하는 일 (한 번에 한 색, 켤 때 바꿀지 선택)
| 색 | 빛 안의 그림자에게 | 칼에 옮겨붙는 효과 |
|---|---|---|
| 화염 | 초당 4 피해 | 3대마다 화상 |
| 얼음 | 이동 -40% | 3대마다 빙결 |
| 성광 | 실체화 +1초 | 3대마다 자세 붕괴 |
| 귀화 | 빛 안의 그림자가 리라를 못 봄 | 3대마다 눈멂 |
| 생명 | — | 처형마다 체력 1 |
| 번개 | 실체화된 적 120px 안 그림자도 함께 실체화 | 3대마다 감전 |

### 2-4. 빛의 모양 (등잔마다 둘 중 하나, 겹쳐 쌓임)
| 모양 | 효과 |
|---|---|
| 넓은 빛 | 빛 반경 +20% (최대 3번) |
| 오래 타는 빛 | 던진 빛 +3초 |
| 갈라지는 빛 | 던지면 반경 70짜리 빛 두 곳 |
| 빛줄기 | 든 빛이 앞으로 +80px 뻗음, 뒤는 -40% |
| 남는 빛 | 회수 궤적에 빛이 2초 남음 |
| 따라오는 빛 | 던진 빛이 천천히 리라를 따라옴 |

### 2-5. 큰 등잔 (보스)
- 보스를 처형하면 켜짐: 빛 최대 반경 +15% · 강한 모양 1개 (빛 두 개 동시 유지 / 완벽 패링 시 빛 폭발 / 던진 빛에 든 그림자 자동 실체화 유지 등).

## 6. 캐릭터 디자인 — 리라 (확정, 이미지 생성 전)

### 6-1. 그림체
- 아주 작은 도트(캐릭터 키 약 60px)를 정수배로 키운 그림 · 약 3.5등신 데포르메(성인) · 큰 머리·큰 눈 · 1px 검은 외곽선 · 평면 색 · 번짐·그라데이션 없음
- 게임 안 키 약 72px · 1px 어두운 외곽선 · 깔끔한 색 덩어리, 디더링 거의 없음
- 캐릭터당 12~16색 · 강한 포인트 색 하나 · 효과도 같은 픽셀 크기로 작게
- (참고 그림은 그림체만 참고, 캐릭터는 독자 디자인)

### 6-2. 리라
| 부위 | 디자인 |
|---|---|
| 종족 | 사람 (동물 귀·꼬리 없음) |
| 머리 | 크림빛 흰머리, 어깨 길이, 한쪽에 작은 등불 모양 머리 장식 |
| 눈 | 크고 둥근 호박색 |
| 나이·비율 | 20대 성인 여성, 약 4등신 (다리 길고 허리 잘록) |
| 옷 (사신 느낌) | 몸에 딱 붙는 짧은 검은 드레스(옷자락 끝이 해진 듯 뾰족), 목까지 오는 칼라, 짧은 검은 후드 · 검은 스타킹 · 작은 부츠 · 몸과 팔에 감긴 사슬 · 허리 뒤 천 자락 · **검은 옷 + 흰 포인트**(후드·드레스 테두리, 초커, 사슬, 천 자락, 스타킹 윗단) |
| 포인트 색 | 기본 = 등불 주황. **등불 색(속성)에 따라 허리 천 자락·사슬 장식이 함께 바뀜** (화염 주황 · 얼음 하늘 · 성광 금 · 귀화 보라 · 생명 초록 · 번개 노랑) — 코드로 팔레트 교체 |

### 6-3. 무기 — 등불 사슬낫
- **낫:** 짧은 손잡이에 크게 휜 초승달 날. 은색 날 + 1px 밝은 테두리 (불꽃 속에서도 모양이 보이게)
- **사슬 끝 등불:** 낫 손잡이 끝에서 사슬이 나와 끝에 둥근 황동 등불. 평소엔 쥔 사슬에 등불이 매달려 흔들림
- **던지기** = 사슬이 풀리며 등불이 날아감 (사슬 길이 = 사거리 260px)
- **회수** = 사슬을 당겨 끌어옴 → 끌려오는 경로의 그림자 실체화
- **패링** = 사슬을 팽팽히 잡아 막음 → 등불을 던진 동안은 사슬이 풀려 **패링 불가** (설정과 규칙이 일치)

### 6-4. 만들 그림 (원본 확정 후)
원본 1장 → 동작: 서기 · 달리기 · 베기 3종 · 패링 · 구르기 · 점프 · 피격 · 쓰러짐 · 던지기 · 당겨 받기 (12종).
등불을 던진 동안의 빈손 모습은 사슬이 풀린 상태로 그려야 하므로 서기·달리기·베기는 '던진 상태' 버전도 필요할 수 있음 → 원본 확정 후 결정.

## 7. 리라 원본 확정 + 액션 설계

원본: `art/lira2/master-final.png` (111×111, 한 격자·28색). 출처: `art/lira2/user-final-source.webp`.

### 7-0. 그림을 나누는 방식 (낫이 꺾이지 않게)
| 부분 | 만드는 법 |
|---|---|
| 몸 (리라) | 생성 → 원본 격자·팔레트 보정. **무기 없이 쥐는 손 자세만** |
| 낫 | 원본에서 떼어 낸 **딱딱한 그림 한 장**. 코드가 손 위치에 붙여 각도만 돌림 → 어떤 동작에서도 모양이 같음 |
| 사슬·등불 | **코드로** 그림 (픽셀 사슬 고리). 자루 끝 → 몸에 감긴 사슬 → 등불 |

### 7-1. 사슬
- 평소: 자루 끝에서 나온 사슬이 **몸(허리)에 두세 바퀴 감기고**, 남은 끝에 등불이 허리 옆에 매달려 흔들림.
- 던지기: 감긴 사슬이 **한 바퀴씩 풀리며** 길어지고 등불이 날아감 (최대 260px).
- 회수: 사슬을 당기면 등불이 돌아오고 사슬이 **다시 몸에 감김**.

### 7-2. 액션 — 낫 액션 + 사슬낫 액션 섞기
| 버튼 | 등불을 든 상태 (낫 중심) | 등불을 던진 상태 (사슬 중심) |
|---|---|---|
| 공격 1 | **휩쓸기**: 낫을 앞으로 크게 가로로 | **사슬 채찍**: 자루를 휘둘러 사슬 끝 등불을 앞으로 내리침 |
| 공격 2 | **되감기 올려베기**: 자루를 돌려 날을 아래→위 (적 띄움) | **사슬 감기**: 등불이 적을 한 바퀴 감아 묶음 (잠깐 못 움직임) |
| 공격 3 | **원월 베기**: 낫을 머리 위로 한 바퀴 (앞뒤) | **끌어 베기**: 감은 적을 사슬로 당겨 끌어와 낫으로 벰 |
| 공격 길게 | **갈고리 당기기**: 낫 끝으로 멀리 있는 그림자를 걸어 빛 안으로 | **사슬 진자**: 등불을 크게 원으로 휘둘러 빛이 호를 그리며 이동 |
| 공중 공격 | **수확 내려찍기**: 떨어지며 날을 세워 찍음 | **사슬 그네**: 높이 걸린 등불을 축으로 날아감 |
| 구르기 | **자루 짚고 넘기**: 자루로 땅을 짚고 적을 뛰어넘음 | 같음 |
| 패링 | **자루 막기** | 불가 (사슬이 풀려 있음) |
| 처형 | **걸어 넘기고 내려찍기**: 낫으로 다리를 걸어 쓰러뜨린 뒤 위에서 | **사슬로 묶고 당겨 베기** |

### 7-3. 만들 몸 동작 (무기 없이) — 낫·사슬은 코드가 붙임
서기 · 달리기 · 휩쓸기 · 올려베기 · 원월 베기 · 갈고리 당기기 · 수확 내려찍기 · 던지기 · 당기기(회수) · 사슬 채찍 · 사슬 진자 · 자루 짚고 넘기 · 자루 막기 · 점프 · 피격 · 쓰러짐 · 처형
각 동작마다 **손 위치·낫 각도 키프레임**을 함께 기록 (코드가 낫을 붙일 자리).

## 7. 구현 현황 (게임에 적용됨)
- **빛·실체:** `js/core/light.js` — 든 빛 90 · 던진 빛 110 · 실체화 0.3초 · 그림자로 0.5초. 그림자에게 칼은 통과 (`phase`).
- **등불 버튼 (U·I / 모바일 '등불'):** 탭 = 160px 던지기 · 길게 = 조준(앞 방향키 멀리, 60~260) · 던진 뒤 탭 = 회수 · 6초 뒤 저절로 회수. 던진 동안 패링 불가, 손에 등불이 없는 그림(`*_nl`)으로 바뀜.
- **패링 데임:** 완벽 3초 · 일반 1.5초 실체화. **회수 궤적:** 1초 실체화.
- **처형:** 빛 안에서만. 처형 = 빛 조각 (일반 3 · 강적 10 · 보스 30). 보스 처형 = 큰 등잔 (빛 +15%). 연속 처형·충격도 빛 안의 적만.
- **보스:** 몸은 늘 실체지만 빛 밖에서 베면 피해·자세 40% (그림자 부위).
- **적 빛 반응:** 구울·창병·순례자는 공격 때가 아니면 빛 밖으로 물러남 · 나방은 던진 등불로 몰림 · 갑각수호자 방패는 빛 쪽 · 암살자는 놓인 등불을 꺼뜨림(2초), 맞으면 든 등불도 2초 꺼짐.
