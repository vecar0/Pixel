# 등불지기 (Lantern Keeper) — 기획서 v1

> 폰 가로 화면 · 픽셀 횡스크롤 · 근접 액션 로그라이크 · 패링 중심
> 작성일 2026-11-19 · 상태: 승인 대기

## 0. 의도 — 왜 만드는가

- **누구를 위해:** 사용자 본인. 폰으로 혼자, 다른 게임을 접을 만큼 몰입해서 계속 하는 게임.
- **핵심 쾌감 (사용자 말 그대로):** "어려운 걸 내 컨트롤과 반응속도로 해냈을 때의 쾌감."
- **그래서:** 승패는 **실력**이 가르고, 성장(빌드)은 실력을 *표현하는 방식*을 넓혀 줄 뿐 실력을 대신하지 않는다.
- **그림 수준:** 사용자가 보여준 레퍼런스 `design/reference/art-target-01.png` (고해상도 하이비트 픽셀, 애니풍 캐릭터, 명암 풍부한 던전, 큰 일러스트 연출) 수준. 스타일·퀄리티만 참고하고 캐릭터·세계관·UI는 전부 오리지널.

## 1. 목표 / 비목표 / 실패 조건

| 구분 | 내용 |
|---|---|
| 목표 | 패링 한 번이 "딱!" 하고 손에 남는 타격감 (히트스톱·불꽃·화면 흔들림·사운드) |
| 목표 | 보스를 처음 깼을 때 "내가 해냈다"가 확실한 난이도 곡선, 클리어 후에도 더 높은 난이도로 계속할 이유 |
| 목표 | 한 판 10~15분, 죽으면 5초 안에 다시 시작 |
| 목표 | 레퍼런스급 픽셀 비주얼 (어둠 + 따뜻한 등불빛 대비) |
| 비목표 (v1) | 추가 플레이어블 캐릭터, 온라인·랭킹, 과금, 스토리 컷신 대량 |
| **실패 조건** | 반복 파밍으로 스탯을 올려 *실력 없이* 깰 수 있게 되는 것 |
| **실패 조건** | 예고 없는 공격·화면 밖 공격·어둠에 가려 안 보이는 공격으로 맞는 것 (억울한 죽음) |
| **실패 조건** | 터치 입력이 씹히거나 늦어서 패링이 실패하는 것 |
| **실패 조건** | 폰에서 프레임이 떨어져 타이밍이 흔들리는 것 |

## 2. 제약

- **플랫폼:** 폰 브라우저 (가로), PWA로 홈 화면 추가. PC 브라우저도 키보드로 플레이 가능.
- **기술:** HTML5 Canvas 2D + 순수 JS ES 모듈, 빌드 도구 없음. 기존 저장소의 PWA·폰트(Galmuri)·테스트 구조 재사용.
- **이미지 생성:** Higgsfield. **크레딧 최소화** — 매 생성 전 예상 비용을 사용자에게 알리고, 싼 모델로 시안 → 확정본만 고품질.
- **이펙트:** pixelfx (무료, 코드). **스프라이트 후처리:** agent-sprite-forge (키잉·슬라이스·팔레트·QA).
- **코딩 원칙:** 카파시 스킬(단순함, 작은 단위, 검증 가능한 진행) 적용.

## 3. 접근 방식 (검토한 것)

| 안 | 내용 | 결과 |
|---|---|---|
| **A. 근접 액션 (회피 + 패링 + 보스 패턴)** | 실력 쾌감이 가장 직접적. 버튼 5개라 폰 조작이 다소 빡빡 | **채택** (사용자 선택) |
| B. 탄막 회피 (자동 공격) | 조작 단순, 쾌감이 "피했다"에 머묾 | 탈락 |
| C. 파티 (리더 조작 + 동료 자동) | 볼거리 크지만 내 컨트롤 비중이 묽어짐 | 탈락 |

| 기술 안 | 결과 |
|---|---|
| **웹 Canvas + JS (기존 저장소 기반)** | **채택** — 폰에서 바로 실행, 여기서 자동 테스트·스크린샷 가능 |
| Godot 등 네이티브 엔진 | 탈락 — 설치·빌드 무겁고 이 환경에서 검증 어려움 |

세계관 후보 3개(등불지기 / 되감기는 시계탑 / 검의 무덤) 중 **등불지기** 채택 (사용자 선택).

## 4. 세계관

- **무대:** 빛이 꺼져 가는 지하 왕국 '할로우데일'. 지상에는 마지막 남은 등대가 있는 **등대 마을**.
- **이야기 골격:** 지하 각 지역의 '대등(大燈)'이 하나씩 꺼지면서 어둠의 짐승들이 올라온다. 등대의 불도 약해진다. 순례자 **리라**가 사슬 랜턴을 들고 내려가 대등을 다시 켠다.
- **로그라이크 정당화:** 리라가 쓰러지면 랜턴의 불씨가 그녀를 등대로 되돌려 보낸다. 다시 켠 대등은 꺼지지 않고, 그 빛만큼 마을이 살아난다(해금).
- **연출 톤:** 대사는 짧고 담담하게. 텍스트는 최소, 분위기는 그림과 빛으로.

## 5. 주인공 — 리라 (사용자 확정)

| 항목 | 내용 |
|---|---|
| 정체 | 등불 순례자. 10대 후반, 키가 큰 편, 단호한 눈매 (늠름함) |
| 머리 | 은백발 긴 포니테일 — 등불빛을 받으면 주황빛으로 물듦, 움직일 때 휘날림 |
| 눈 | 호박색(앰버) — 어둠 속에서 은은하게 빛남 |
| 복장 | 후드 달린 짧은 망토, 몸에 붙는 여행복, 허리에 기름병·부적. 갑옷 없음 (기사 아님) |
| 무기 | 오른손 한손검 (공격) + 왼손 사슬 달린 고풍스러운 랜턴 (패링) |
| 성격 | 과묵·담담, 속은 다정. 보스 처치 시 짧은 한마디 + 작은 미소 |
| 스프라이트 | 6~7등신, 게임 내 높이 약 56px (내부 해상도 640×360 기준) |

**추후 여캐 (v1 범위 안의 NPC):** 등대 마을 상인, 대장장이, 기록관 등 — 각자 사용자에게 세부 디자인을 물어본 뒤 제작. 보스 중 인간형(침수 성녀, 흑염의 순례자)도 동일.

## 6. 전투 시스템 (핵심)

고정 타임스텝 **60틱/초**. 아래 프레임(f) = 1/60초.

### 6.1 리라 행동

| 행동 | 수치 | 비고 |
|---|---|---|
| 이동 | 최고 속도 150px/s, 가속 4f, 감속 3f | 미끄러짐 거의 없음 (정밀 조작) |
| 점프 | 가변 높이 (누르는 시간), 최대 72px, 코요테 타임 6f, 입력 버퍼 8f | 공중 1회 추가 점프는 각인으로만 |
| 공격 (검 3연타) | 피해 10 / 10 / 18, 각 타 선딜 4f · 판정 3f · 후딜 10f | 후딜은 **회피·패링으로 즉시 캔슬** 가능 |
| 공중 공격 | 피해 10, 1회 | |
| **패링 (랜턴 휘두르기)** | 입력 즉시 판정 시작, **0~6f = 완벽 패링**, **7~12f = 일반 패링**, 이후 18f 회수 동작(무방비) | 연타 방지: 실패 시 회수 동작 동안 재입력 불가 |
| 회피 (구르기) | 22f 동안 96px 이동, **2~13f 무적** (12f), 종료 후 6f 경직 | 쿨다운 없음, 스태미나 없음 |
| 필살 '등불 해방' | 빛 게이지 100 소모, 화면 범위 화염 피해 60 + 적 탄 소거, 시전 중 무적 | 랜턴 기름 종류로 형태 변화 (8장) |
| 회복 '기름병' | 한 판 3회, 사용 40f(이동 느려짐), 하트 2 회복 | 휴식방에서 충전 |

- **체력:** 하트 5칸. 일반 피격 1칸, 보스 강공격 2칸. 피격 후 무적 60f.
- **입력 버퍼:** 모든 행동 입력은 8f 동안 버퍼링 (후딜 중 누른 패링이 씹히지 않게).

### 6.2 패링 결과

| 결과 | 효과 |
|---|---|
| **완벽 패링** | 피해 0 · 히트스톱 8f · 큰 불꽃(pixelfx) · 짧은 화면 흔들림 · 빛 +25 · 적 **자세 게이지 큰 피해** · 원거리 탄은 **반사** · 폰 진동 30ms(지원 기기) |
| 일반 패링 | 피해 0 · 히트스톱 3f · 작은 불꽃 · 빛 +10 · 자세 게이지 작은 피해 · 탄은 소멸 |
| 패링 불가 공격 | **붉은 테두리 + 붉은 섬광 예고**. 패링하면 피격. 회피로만 대응 |

### 6.2.1 패링 세부 규칙 (빌더 판단으로 확정)

- **방향:** 랜턴 휘두르기는 리라 **정면** 판정(앞 40px, 위아래 넉넉히). 등 뒤에서 오는 공격은 패링되지 않음 → 적을 마주 보는 것이 실력의 일부.
- **다단 공격:** 한 번의 패링 판정 창(0~12f) 안에 들어온 공격·탄은 **전부** 패링됨.
- **성공 후 회수 취소:** 패링이 하나라도 성공하면 18f 회수 동작이 사라지고 **4f 뒤 다시 패링·공격·회피 가능**. → 3연 찌르기·3연 물탄은 "3번 연속 타이밍 맞추기"가 됨. 실패(아무것도 안 막음)만 18f 무방비.
- **연속 공격 간격:** 다단 공격의 타와 타 사이는 최소 16f (재패링 가능한 간격 보장).
- **패링 대결 (흑염의 순례자):** 보스가 리라의 공격을 패링하면 리라가 8f 경직, 그 사이 보스 반격 예고(14f) → 리라가 패링으로 받아칠 수 있음.

### 6.2.2 입력 지연 보정

- 설정에 **타이밍 보정** (-50ms ~ +100ms, 10ms 단위) + 보정 도우미(박자에 맞춰 탭 → 평균 지연 측정).
- 판정은 입력이 *발생한 시각*(터치 이벤트 timeStamp) 기준으로 역산해서 적용.
- 난이도 목표 (빌더 판단): 첫 클리어까지 약 15~25판. 지역1 보스는 3판 안에 처음 잡을 수 있게.

### 6.3 적의 공격 규칙 (억울함 방지)

- 모든 공격은 **예고 동작 ≥ 18f** (일반 적), 보스 빠른 공격도 **≥ 14f**. 예고 중 무기 끝이 흰색/붉은색으로 번쩍임.
- 공격 판정은 예고가 **화면 안에서 보였을 때만** 시작. 화면 밖 적은 공격하지 않음.
- 어둠 연출(9장)은 **적과 적 예고를 절대 가리지 않음** — 적·탄·예고 이펙트는 항상 조명 레이어 위에 그림.
- 동시에 공격 개시하는 일반 적은 최대 2마리 (공격 토큰 시스템).

### 6.4 자세 게이지 (그로기)

- 엘리트·보스는 자세 게이지 보유. 완벽 패링 = 게이지의 25%, 일반 패링 = 8%, 일반 공격 = 2%.
- 가득 차면 **그로기 3초** → 리라가 다가가 공격 버튼을 누르면 **처형** (최대 체력의 15% 피해 + 연출).
- 게이지는 2초간 패링을 안 당하면 서서히 회복. → 패링을 노리는 플레이가 가장 빠른 공략.

### 6.5 빛 게이지

- 0~100. 패링(+25/+10), 처치(+3)로 충전. 시간 경과로는 줄지 않음.
- 게이지가 높을수록 리라 주변 조명 반경이 넓어짐 (분위기용, 시야 불이익 없음).
- 100에서 필살 버튼이 빛남.

## 8. 한 판의 구조 (런)

```
등대 마을(거점) ─▶ 지역1 이끼 묘지 ─▶ 지역2 침수 대성당 ─▶ 지역3 유리 광산 ─▶ 지역4 꺼진 태양의 심연
                   (방 4개 + 보스)    (방 4개 + 보스)      (방 4개 + 보스)    (방 3개 + 최종 보스)
```

- 지역마다 방 4개 정도. 방 끝에 **문 2개 중 하나 선택** (문 위에 방 종류 아이콘 표시).
- 한 판 목표 시간 10~15분.

| 방 종류 | 내용 |
|---|---|
| 전투 | 문 잠김, 적 2~3웨이브. 클리어 시 **각인 3택1** |
| 엘리트 | 엘리트 1~2 + 잡몹. 보상: 희귀 각인 3택1 |
| 휴식 (작은 등불) | 기름병 전부 충전 또는 하트 2 회복 중 택1 |
| 상점 | 불씨(런 화폐)로 각인·기름병 구매 |
| 시련 | 제한 조건(예: 맞으면 실패, 패링만으로 처치) 달성 시 큰 보상 |
| 보스 | 지역 끝. 처치 시 대등 점화 + 하트 전부 회복 |

- **불씨 (런 화폐):** 적 처치·방 클리어로 획득, 상점에서 사용, 런 종료 시 소멸.
- **등불 조각 (영구 화폐):** 보스 처치·시련 성공으로 획득, 마을 해금에 사용 (10장).

## 9. 빌드 — 각인 (Relic)

"더 세지는 것"보다 **"실력을 다르게 표현하게 하는 것"** 위주. v1 목표 24종. 예시:

| 각인 | 효과 | 계열 |
|---|---|---|
| 반향 | 완벽 패링 시 전방으로 불꽃 검기 발사 | 패링 |
| 불씨 연쇄 | 완벽 패링 연속 성공마다 공격력 +10% (최대 5중첩, 피격 시 초기화) | 패링 |
| 잔광 | 회피 무적 중 적을 통과하면 다음 공격 치명타 | 회피 |
| 그림자 걸음 | 회피 거리 +40%, 무적 +3f | 회피 |
| 사슬 휘감기 | 패링 후 적을 끌어당김 | 패링 |
| 두 번째 날개 | 공중 점프 1회 | 이동 |
| 순례자의 인내 | 하트 +1 | 생존 (흔함) |
| 기름 주머니 | 기름병 +1 | 생존 |
| 화염 칼날 | 3타째 화상 부여 (초당 피해 3, 3초) | 공격 |
| 처형자 | 처형 피해 +100% | 자세 |

**랜턴 기름 (필살 변형, 마을에서 해금 후 출발 시 선택):**

## 10. 메타 진행 — 등대 마을

- **원칙: 영구 스탯 강화 없음.** 해금은 *선택지*만 늘린다.
- 등불 조각으로 해금:
  - 각인 풀 확장 (24종 중 시작 12종, 나머지 해금)
  - 랜턴 기름 2종
  - **연습장:** 처치한 보스 재도전 (패턴 연습)
  - **어둠 단계 1~10:** 첫 클리어 후 개방. 단계마다 규칙 추가 (적 예고 단축 -2f, 엘리트 증가, 회복 감소, 보스 신규 패턴 …). 단계별 클리어 기록 저장.
- **기록:** 최고 단계, 최단 클리어 시간, 노히트 보스 처치 배지, 완벽 패링 누적 수.
- NPC 여캐(상인·대장장이·기록관)는 해금 진행에 따라 대사가 늘어남.

## 11. 적 · 보스

### 일반 적 (v1: 6종 + 엘리트 변종)

| 이름 | 지역 | 체력 | 패턴 | 패링 |
|---|---|---|---|---|
| 이끼 망자 | 1 | 30 | 걸어와서 내려베기 (예고 20f) | 가능 |
| 등불 나방 | 1·3 | 12 | 공중 대기 → 직선 돌진 (예고 18f) | 가능 |
| 해골 창병 | 2 | 40 | 긴 찌르기 / 3연 찌르기 | 가능 |
| 침수 사제 | 2 | 25 | 원거리 물탄 3발 | 가능 (완벽 시 반사) |
| 갑각 파수꾼 | 3 | 70 | 정면 방패(정면 피해 무효), 잡기 | 잡기는 **불가** |
| 그림자 자객 | 4 | 35 | 순간이동 후 베기 (예고 16f) | 가능 |

- **엘리트:** 체력 ×2.5, 자세 게이지 보유, 패턴 1개 추가, 붉은 오라.
- 적 수치는 1~4지역에서 체력 ×1.0 / 1.3 / 1.6 / 2.0.

### 보스 (지역당 1, 페이즈 2개씩)

| 보스 | 지역 | 핵심 패턴 | 공략 포인트 |
|---|---|---|---|
| 무덤종 (종을 든 묘지기 거인) | 1 | 종 휘두르기(패링), 내려찍기 충격파(점프), 2페이즈 종소리 탄막 | 패링 입문 — 느리고 정직함 |
| 침수 성녀 | 2 | 물창 투척(완벽 패링 시 반사), 수면 상승(발판 이동), 2페이즈 3연 돌진 | 반사로 큰 피해 |
| 유리 여왕거미 | 3 | 수정 레이저(**패링 불가**, 회피), 새끼 거미 소환, 천장 낙하 | 회피와 패링 전환 |

## 12. 그림 · 사운드 파이프라인

### 해상도와 화면
- 내부 해상도 **640×360**, 정수 배율로 확대(nearest). 폰 비율 차이는 좌우 여백(레터박스) 대신 **가로 시야 확장**으로 흡수 (최대 780×360).
- 레이어: 원경 패럴랙스 3장 → 타일 지형 → 오브젝트·적 → 리라 → 조명(어둠) 레이어 → 적 예고·탄·이펙트 → UI.

### 크레딧 최소 계획 (Higgsfield)

| 대상 | 생성 | 비고 |
|---|---|---|
| 리라 마스터 (전신, 픽셀 스타일) | 싼 모델 시안 2~3장 → 확정 1장 | **사용자 승인 후** 다음 단계 |
| 리라 포즈 시트 | 행동 묶음별 시트 3~4장 (대기·달리기 / 공격·패링 / 회피·점프·피격 / 필살) | 마스터를 레퍼런스로, 슬라이스·정리는 agent-sprite-forge |
| 타이틀 키 일러스트 | 1장 | 레퍼런스의 큰 일러스트 연출 대응 |
| 일반 적 6종 | 종별 시트 1장 | |
| 보스 4종 | 마스터 1 + 포즈 시트 1~2 | |
| 지역 배경 4종 | 지역별 원경 1~2장 | 타일은 코드로 |
| NPC 여캐 3명 | 초상 1장씩 | 디자인 질문 후 |

- 예상 총 생성 약 40~50회. **매 묶음 시작 전에 잔액과 예상 비용을 보고**하고 승인 후 진행.
- 생성이 안 맞으면 같은 걸 반복 생성하지 않고, 코드 보정(agent-sprite-forge 후처리, codeart2d로 부분 수정)을 우선.
- **이펙트:** 패링 불꽃, 검 궤적, 피격, 화상, 처치, 필살 화염, 줍기 반짝임은 pixelfx로 만들어 색을 등불 팔레트(앰버·주황·크림)에 맞춤.
- **조명:** 어둠 오버레이 캔버스에 방사형 그라데이션으로 빛 구멍(리라 랜턴, 벽 등불, 탄). 저렴한 방식.
- **사운드:** WebAudio 합성 효과음 (기존 audio.js 방식). 패링 '챙' 소리는 최우선으로 공들임. BGM은 지역별 짧은 루프.

## 15. 완료 기준 (각 항목 = 테스트 1개)

**전투**
- [ ] 적 공격 판정 6f 전에 패링을 누르면(완벽 구간) 피해 0, 히트스톱 8f, 빛 +25가 된다
- [ ] 일반 패링 구간(7~12f)이면 피해 0, 빛 +10이 된다
- [ ] 패링 불가 공격을 패링하면 하트가 깎인다
- [ ] 패링 실패 후 18f 동안 패링을 다시 누를 수 없다
- [ ] 구르기 2~13f 동안 적 공격에 맞아도 하트가 줄지 않는다
- [ ] 공격 후딜 중 회피·패링 입력이 즉시 실행된다
- [ ] 후딜 중 누른 입력이 8f 안에 실행 가능해지면 실행된다 (버퍼)
- [ ] 완벽 패링한 원거리 탄이 반대로 날아가 적에게 피해를 준다
- [ ] 자세 게이지가 가득 차면 그로기 → 공격 입력 시 처형이 발동한다
- [ ] 빛 100에서 필살이 발동하고 게이지가 0이 된다
- [ ] 모든 적 공격에 18f 이상(보스 14f 이상) 예고가 있다 (데이터 검사)
- [ ] 화면 밖 적은 공격을 시작하지 않는다
- [ ] 동시에 공격을 시작하는 일반 적은 2마리 이하이다

**런 · 진행**
- [ ] 전투방 클리어 시 각인 3택1이 뜨고, 고른 각인 효과가 실제로 적용된다
- [ ] 방 끝 문 2개에 방 종류 아이콘이 보이고, 고른 쪽으로 이동한다
- [ ] 휴식방에서 기름병 충전 또는 회복을 고를 수 있다
- [ ] 보스 처치 시 다음 지역으로 넘어가고 하트가 전부 회복된다
- [ ] 하트 0이면 런 종료 화면이 뜨고, '다시' 후 5초 안에 조작 가능하다
- [ ] 4지역 보스 처치 시 클리어 화면 + 어둠 단계 1 해금
- [ ] 등불 조각·해금·기록이 새로고침 후에도 유지된다

**조작 · 화면**
- [ ] 모바일 가로에서 스틱 + 버튼 6개가 동시에(멀티터치) 동작한다
- [ ] 터치 입력이 다음 틱에 바로 반영된다 (지연 ≤ 1틱)
- [ ] 세로로 들면 '가로로 돌려주세요' 안내가 뜬다
- [ ] PC 키보드로 모든 행동이 가능하다

**품질**
- [ ] 리라 스프라이트 대기·달리기·공격 3타·패링·회피·점프·낙하·피격·필살 모션이 모두 있다
- [ ] 적·적 예고·탄은 어둠 레이어에 가려지지 않는다 (스크린샷 검사)
- [ ] 최악 장면에서 프레임당 JS ≤ 8ms (headless 측정)
- [ ] 브라우저 콘솔 에러 0건
